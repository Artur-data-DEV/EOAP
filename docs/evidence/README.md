# Evidências

Esta seção armazena evidências de execução, testes, demos e compliance.

## Propósito

- Suporte a revisões de Architecture Review Board (ARB)
- Evidências para auditorias (SOX, LGPD, ISO)
- Rastreabilidade do que foi demonstrado e validado

## Conteúdo recomendado

- Prints e vídeos de demos
- Resultados de testes manuais
- Logs de deploy
- Relatórios gerados pelo Report Agent

Mantenha os arquivos organizados por data ou por Sprint.
