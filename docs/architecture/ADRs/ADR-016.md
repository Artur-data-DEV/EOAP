## Contexto

A EOAP requires data retention and archiving strategy for compliance (SOX 7 years) and performance.

## Decisão

Audit 7 anos; events 90 dias; archiving antes de volume produtivo.

## Rationale

- Compliance SOX (7 anos)
- Performance (archiving)
- Capacity planning
- Alinhado com best practices

## Alternativas Consideradas

### Alternativa 1: Retenção permanente para tudo
**Rejeitado**: Performance degradation, custo alto

### Alternativa 2: Sem archiving
**Rejeitado**: Performance degradation em volume produtivo

## Consequências

### Positivas
- Compliance SOX
- Performance otimizada
- Capacity planejado

### Negativas
- Overhead de archiving
- Complexidade de implementação

## Implementation

- Audit trail: 7 anos (SOX)
- Event processing: 30 dias active, 90 dias archive
- User access: 7 anos após offboarding
- Risk evidence: 7 anos
- Archiving ativo para audit trail
- Archiving passivo para outros dados
