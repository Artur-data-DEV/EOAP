## Contexto

A EOAP requires decision between pure event-driven architecture (EDA) vs hybrid sync/async for compliance and debuggability.

## Decisão

EDA restrita a integração e notificação; SYNC_CRITICAL para conformidade (revogação, aprovação commit, risk on submit).

## Rationale

- Conformidade (offboarding < 60s)
- Debuggability (sync para operações críticas)
- EDA para integrações (IAM, HRIS, SIEM)
- Trade-off aceito: menos purismo EDA

## Alternativas Consideradas

### Alternativa 1: Pure EDA
**Rejeitado**: Difícil debuggability, risco de compliance

### Alternativa 2: Pure sync
**Rejeitado**: Escalabilidade limitada, não alinhado best practices

## Consequências

### Positivas
- Conformidade garantida
- Debuggability facilitada
- EDA para integrações

### Negativas
- Menos purismo EDA
- Complexidade híbrida

## Implementation

- SYNC_CRITICAL: offboarding revogação, risk calculation
- ASYNC: IAM provision/deprovision, HRIS sync, SIEM alert
- Event-driven para integrações
- Correlation ID para traceability
