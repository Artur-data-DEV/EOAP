## Contexto

A EOAP requer audit trail imutável e completo para compliance (SOX, ISO 27001).

## Decisão

`x_eoap_audit_trail` via EOAP_AuditLogger only (write-only); sys_audit complementa.

## Rationale

- Audit trail imutável (append-only)
- Controle completo de escrita
- Compliance SOX (7 anos)
- Correlation ID tracking
- Alinhado com best practices

## Alternativas Consideradas

### Alternativa 1: sys_audit apenas
**Rejeitado**: Insuficiente para eventos customizados, menos controle

### Alternativa 2: Audit trail com update/delete
**Rejeitado**: Risco de adulteração, não compliance

## Consequências

### Positivas
- Audit trail imutável
- Controle completo
- Compliance SOX

### Negativas
- Requer Script Include dedicado
- Overhead de manutenção

## Implementation

- Tabela x_eoap_audit_trail (append-only)
- Script Include EOAP_AuditLogger
- ACL: create via EOAP_AuditLogger only
- ACL: read via x_eoap_admin, x_eoap_auditor only
- ACL: write/delete none
