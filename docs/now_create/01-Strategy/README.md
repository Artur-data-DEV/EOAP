# 01 - Strategy (Now Create)

High-level strategy, vision, business case, stakeholders, and success criteria for EOAP.

This folder is intentionally lightweight for the template. When using EOAP as a base for a new project, populate this section first with your organization's specific strategy.

## Recommended Content

- Vision and problem statement
- Business objectives and KPIs (e.g. reduction in manual offboarding time, audit findings)
- Stakeholders (Security, HR, Compliance, IT, Business Application Owners)
- Scope boundaries (what is in/out for v1)
- Risk and compliance drivers (SOX, LGPD, ISO, etc.)

The Agentic Supervisor can help generate initial content for this phase from a high-level prompt.
