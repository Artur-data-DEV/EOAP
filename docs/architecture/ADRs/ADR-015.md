## Contexto

A EOAP depends on CMDB quality for access governance and risk calculation.

## Decisão

EOAP_CMDBQualityService; gates antes de operações críticas (risk/access).

## Rationale

- Fail-safe quando CMDB quality baixa
- Força melhoria de CMDB
- Evita decisões baseadas em dados incorretos
- Alinhado com best practices

## Alternativas Consideradas

### Alternativa 1: Sem CMDB quality gates
**Rejeitado**: Risco de decisões incorretas, não fail-safe

### Alternativa 2: CMDB quality como warning apenas
**Rejeitado**: Insuficiente para fail-safe

## Consequências

### Positivas
- Fail-safe
- Força melhoria CMDB
- Evita decisões incorretas

### Negativas
- Overhead de implementação
- Pode bloquear operações

## Implementation

- Script Include EOAP_CMDBQualityService
- Gates: CMDB quality ≥ 95%
- Se quality < 95%: band Unknown, access bloqueado
- CMDB Quality Report diário
- Notificação se quality < 90%
