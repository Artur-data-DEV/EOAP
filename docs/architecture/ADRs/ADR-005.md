## Contexto

A EOAP requer interface para usuários solicitarem acesso, exceções e outras ações governadas.

## Decisão

Service Catalog e Record Producers para solicitações estruturadas.

## Rationale

- Service Catalog é padrão ServiceNow
- Record Producers validam input
- Aprovações nativas
- UX consistente
- Alinhado com best practices

## Alternativas Consideradas

### Alternativa 1: Form list
**Rejeitado**: Menos user-friendly, sem validação nativa

### Alternativa 2: Portal customizado
**Rejeitado**: Overhead de desenvolvimento, não alinhado OOB First

## Consequências

### Positivas
- UX consistente
- Validação nativa
- Aprovações nativas

### Negativas
- Limitações em customização avançada

## Implementation

- Catalog Item: Access Request
- Catalog Item: Access Exception
- Record Producers para validação
- Aprovações nativas
