# Governança

Esta seção trata de compliance, controles internos, auditoria e políticas do EOAP.

## Tópicos

- Controles SOX / LGPD / ISO
- Audit Trail e imutabilidade
- RBAC e princípios de menor privilégio
- Cross-scope rules
- Processo de revisão arquitetural (ARB)

## Relação com o código

Toda regra de governança implementada em `src/fluent/governance/` deve ter contrapartida documentada aqui.

O Audit Trail (`x_eoap_audit_trail`) é o principal mecanismo de evidência para esta área.
