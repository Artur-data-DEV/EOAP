## Contexto

A EOAP scoped application `x_eoap` requires access to global tables (CMDB, change_request).

## Decisão

Regras cross-scope explícitas por tabela global; validação ATF Sprint 0.

## Rationale

- Governança clara de cross-scope
- Segurança explícita
- ATF validation
- Alinhado com best practices

## Alternativas Consideradas

### Alternativa 1: Cross-scope implícito
**Rejeitado**: Risco de segurança, não governado

### Alternativa 2: Sem cross-scope
**Rejeitado**: Impossível acessar CMDB, não funcional

## Consequências

### Positivas
- Governança clara
- Segurança explícita
- ATF validation

### Negativas
- Overhead de configuração
- Requer ATF maintenance

## Implementation

- ACL cross-scope para cmdb_ci_business_app
- ACL cross-scope para cmdb_ci_service_discovered
- ACL cross-scope para change_request (campos EOAP)
- ATF suite EOAP_ATF_Security_Negative
- Validation Sprint 0
