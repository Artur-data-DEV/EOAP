## Contexto

A EOAP requer cálculo de risco de mudança com múltiplos fatores e banding.

## Decisão

DT pesos → RiskEngine agregação → DT banding; evidência em x_eoap_risk_evidence; CMDB indisponível = band Unknown.

## Rationale

- Separação de concerns
- Pesos configuráveis via DT
- Banding configurável via DT
- Evidência para auditoria
- Fail-safe quando CMDB indisponível

## Alternativas Consideradas

### Alternativa 1: Script único para tudo
**Rejeitado**: Menos configurável, harder to maintain

### Alternativa 2: Sem fail-safe CMDB
**Rejeitado**: Risco de cálculo incorreto, não fail-safe

## Consequências

### Positivas
- Configurável via DT
- Evidência para auditoria
- Fail-safe CMDB

### Negativas
- Complexidade de três camadas
- Overhead de implementação

## Implementation

- DT_Risk_Weights (pesos por fator)
- Script Include EOAP_RiskEngine (agregação)
- DT_Risk_Banding (banding por score)
- Tabela x_eoap_risk_evidence (evidência)
- Fail-safe: CMDB indisponível → band Unknown
