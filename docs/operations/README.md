# Operações

Runbooks, procedimentos de manutenção e suporte para o EOAP em produção.

## Tópicos futuros

- Monitoramento do Scheduled Job de Reconciliação
- Procedimentos de recuperação de desastres para dados de acesso

- Suporte a usuários (admin e auditor)

Por enquanto, a operação é focada em PDI. Runbooks completos serão criados quando o projeto avançar para instâncias de desenvolvimento/teste.
